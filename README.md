# 📘 Assignments-Maths

Welcome to the **Assignments-Maths** repository! This collection showcases a series of Python-based mathematical assignments completed as part of my coursework at Suresh Gyan Vihar University. Each script is designed to tackle specific mathematical problems, demonstrating practical applications of programming in solving mathematical tasks.

---

## 📂 Repository Contents

This repository includes the following Python scripts:

- **Student Information System**: Manage and display student records.
- **Calculate Sum**: Compute the sum of a list of numbers.
- **Area Calculations**: Determine the area of various shapes like circles and rectangles.
- **Factorial Calculator**: Calculate the factorial of a given number.
- **HCF Finder**: Find the Highest Common Factor (HCF) of two numbers.
- **Duplicate Remover**: Remove duplicate elements from a list.
- **Vowel Set Generator**: Identify and display vowels present in a given string.
- **Statistics Module**: Perform basic statistical operations like mean, median, and mode.
- **Student Record Manager**: Add, update, and delete student records.
- **Tuples with Cubes**: Generate tuples containing numbers and their cubes.
